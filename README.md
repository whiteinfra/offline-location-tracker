# LocationApp

## Лабораторна робота: «Фіча: геолокація + кеш (offline)»

### Опис
Проєкт реалізує функціонал отримання поточної геолокації пристрою, збереження її в локальну базу даних (Room) та відображення списку збережених точок. Додаток працює в офлайн-режимі, використовуючи кешовані дані як єдине джерело правди (Single Source of Truth).

### Архітектура
Проєкт побудований за принципами MVVM (Model-ViewModel-Intent):
- **Model**: `LocationEntity` (Room Entity), `LocationDao` (Data Access Object), `AppDatabase`.
- **Repository**: `LocationRepository` – відповідає за взаємодію з `FusedLocationProviderClient` та базою даних.
- **ViewModel**: `LocationViewModel` – оркеструє отримання даних та керує станом UI.
- **UI**: Jetpack Compose – декларативний опис інтерфейсу.

### Технології
- **Kotlin & Coroutines/Flow**: для асинхронної роботи.
- **Jetpack Compose**: для створення сучасного інтерфейсу.
- **Room**: для локального зберігання даних.
- **Google Play Services Location**: для отримання координат.
- **Hilt**: для впровадження залежностей (Dependency Injection).

### Інструкція запуску
1. Клонуйте репозиторій.
2. Відкрийте проєкт в Android Studio (Ladybug або новіше).
3. Дочекайтеся завершення Gradle Sync.
4. Запустіть додаток на фізичному пристрої або емуляторі з підтримкою Google Play Services.
5. Надайте дозволи на доступ до геолокації при першому запуску.
6. Натисніть "Отримати позицію" для збереження поточних координат.

### Функціонал
- Запит runtime-дозволів.
- Отримання поточної локації (Latitude, Longitude, Accuracy).
- Автоматичне оновлення списку завдяки Flow.
- Можливість очищення всієї історії локацій.
- Робота без доступу до інтернету.
